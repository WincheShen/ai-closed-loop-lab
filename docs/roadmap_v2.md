## 目标（不变）

- 自主运营的智能炒股平台
- 多人格并行（短线热点 + 段永平 + 巴菲特）

## 关键原则

1. **信号一定能变成成交** — 不再有 68% 空转
2. **成交一定按纪律止损** — 不再有 -80.8% 的爆仓
3. **每日一定有内容发布** — 不再是 0 篇
4. **每个人格独立账户、独立胜率、独立演化** — 表现好的加仓，差的减仓
5. **每个改动必须有实盘数据验证** — 不看 backtest 曲线，看真实成交

## 与 v1 版本的区别

v1（docs/roadmap_to_60pct.md）关注的是"加数据源、加规则"，本质上是"加更多信号"。

v2 认清了 3 个残酷现实：
1. 加信号没用，信号不成交才是真问题
2. 加规则没用，规则被 LLM 绕过才是真问题
3. 加人格没用，人格没跑起来才是真问题

**v2 的核心是"让系统真的工作"，而不是"让系统看起来复杂"。**
