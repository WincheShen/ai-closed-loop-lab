# Roadmap: 41% → 60% 胜率

> 起点：2026-06-28 实盘数据 17 笔已完成交易，41.2% 胜率
> 目标：稳定 60%+ 胜率的自主 AI 投资平台

## 目标定义

一个能**自主发现热点、评估风险、实际操作、回顾成长**的 AI 金融投资平台。
胜率考核：连续 100 笔交易胜率 ≥ 60%。

## 现状快照（诊断依据）

### 关键数据
| 指标 | 数值 |
|---|---|
| 已完成交易 | 17 笔 |
| 整体胜率 | 41.2% (7胜/9负/1中性) |
| 平均盈亏 | +59.7% (被 held_too_long 拉高) |
| 交易模式 | **100% Mock**（未接实盘） |

### 关键洞察（真实数据挖出来）

1. **已存在可复制的 60% 组合**：`bear regime × 热点板块前排回踩 = 3W/2L = 60%`
2. **5 天强制减仓规则砍掉最大赢家**：6+ 天持仓平均 +201%（含单笔 +554%）
3. **放量突破策略在所有 regime 下负期望**：avg pnl -15.5%，但刚好没触发暂停
4. **53% 退出是止损**：入场质量或止损设置有问题
5. **10 条教训全部单次出现**：学习了但没归纳形成元规则

### 四大能力现状

| 能力 | 完成度 | 主要缺口 |
|---|---|---|
| 热点发现 | 60% | 缺新闻源、龙虎榜、盘中 regime drift |
| 风险评估 | 85% | 无相关性检查、无 Kelly、sector 数据常缺失 |
| 实际操作 | **40%** | **未接实盘（最大瓶颈）** |
| 回顾成长 | 70% | 权重区间保守、元规则未归纳、样本不足 |

## 路径规划（按 ROI 排序）

### 🎯 阶段 1：数据已支持的立即优化（本周）

**预期效果：41% → 50%**

#### 1-1 收紧策略暂停阈值 + 强制 regime 硬门槛
- **文件**：`src/experience_layer/strategy_ledger.py`, `src/agents/strategist/signal_generator.py`
- **改动**：
  - [x] `_SUSPEND_WIN_RATE: 0.30 → 0.40`（让 `放量突破` 立即被暂停）
  - [x] `_MIN_SAMPLE: 3 → 5`（防止过拟合）
  - [x] 在 Strategist 增加硬门槛：`若 strategy × 当前regime 胜率 < 40%，直接 PASS`
- **依据**：`放量突破` 33% 胜率仍在跑；`bear + 热点回踩` 60% 应重点押注

#### 1-2 分级 held_too_long 规则（保护赢家）
- **文件**：`src/agents/reviewer/position_reviewer.py`
- [x] **已实现**：大赢家(>20%)不限时，价值票90/180天阈值，短线3/5/10天分级

#### 1-3 提升入场质量
- **文件**：`src/agents/explorer/scanner.py` 或 `src/agents/reviewer/intraday_loop.py`
- **方案 A**：Explorer 分数阈值 `2.0 → 3.0`（宁缺勿滥）
- **方案 B**：动态止损 `min(-5%, -2×ATR)`（避开日内噪音）
- **依据**：53% 退出是止损，说明入场或止损有一个错了

### 🎯 阶段 2：补齐核心数据源（1-2 周）

**预期效果：50% → 60%**

- **依据**：机构动向是最直接的"聪明钱"信号

#### 2-5 新闻/公告数据源

- **接入点**：
  - [x] LLM 提取 catalyst（业绩预告、政策、重组、订单）
  - [x] 匹配当日候选股加分
  - [x] 填充 TradingState.social_sentiment
- **依据**：情绪面/事件驱动是短线核心，纯技术+资金无法预知

#### 2-6 元规则归纳器
- [x] **已实现**：`src/experience_layer/meta_rule_synthesizer.py`

- **机制**：

  - [x] 输出「近期我总在哪种情境下亏」的元规则
  - [x] 写入 `rules.yaml`（新规则）或 `trading_persona.yaml.avoid_setups`（禁忌）
- **依据**：目前 10 条教训全单次出现，缺"从模式识别到规则化"这一环

### 🎯 阶段 3：真正的"自主"（1 个月）

**预期效果：稳定 60%+**

#### 3-7 实盘接入（最重要的一步）
- [x] **已实现**：miniQMT bridge (`scripts/miniQMT_bridge.py`)
- **步骤**：
  1. [x] 先接 paper trading endpoint，稳定 2 周
  2. [ ] 加账户对账、部分成交、订单撤改
  3. [ ] 灰度切实盘（先 10% 资金，再逐步放开）
- **依据**：当前所有努力都是纸上谈兵，未接实盘 = 未验证

#### 3-8 盘中 regime drift 检测
- [x] **已实现**：`src/agents/cio/regime_drift.py`
- **机制**：
  - [x] 每 5 分钟检查关键指标漂移 > 20%
  - [x] 立即重算 regime → 触发 posture 调整
- **依据**：当前 regime 固定在 9:35/11:35/14:00 判定，错过盘中反转

#### 3-9 动态仓位（简化 Kelly）
- [x] **已实现**：`src/agents/strategist/signal_generator.py`
- **改动**：`position_pct = base × (win_rate / 0.5)`
  - 胜率 70% → 1.4x 仓位
  - 胜率 30% → 0.6x 仓位
- **依据**：固定 2-10% 仓位没利用胜率信息

## 风险 & 假设

- **样本量假设**：需要至少 100 笔实盘交易才能统计显著判断胜率
- **市场周期假设**：现有 17 笔全在 2026-06 一个月内，跨牛熊验证仍缺
- **数据源可用性**：akshare 免费 API 可能限流或改版，需要 fallback
- **实盘接入门槛**：不同券商 API 差异大，选型直接影响 3-7 的工期
